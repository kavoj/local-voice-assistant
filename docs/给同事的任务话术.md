## 一、微信版（直接复制）

老X，麻烦你个事，这周帮我把它部署到会议室那块安卓大屏上。

是个语音助手（企业数字助理）：能语音问公司制度、呼叫员工、发企业微信，还能用语音调度局域网里的电脑（锁屏、截图、播报这些）。

压缩包我发你了（eda-voice-assistant-full.zip），解压后看 `docs/任务说明书-安卓大屏APK部署.md`，照着一路走就行，大概三步：

1）构建机装 JDK17 + Android SDK（说明书 §4 有 mac / win / linux 三套命令），然后进 `android/` 目录跑 `gradle assembleDebug` 出 APK

2）APK 装到大屏：adb 或 U 盘侧载都行，记得开「未知来源」，第一次打开要允许麦克风权限

3）电脑端把后端跑起来：`python3 -m assistant.hud --host 0.0.0.0 --port 8765`，然后把 `android/app/src/main/assets/config.json` 里的 `server_url` 改成这台电脑的局域网 IP，重新构建一次再装

大屏和电脑要在同一个局域网，电脑防火墙放行 8765 端口。

想先看效果：电脑上双击「启动语音助手.command」（Mac）/「启动语音助手.bat」（Windows）就能跑，浏览器开 http://127.0.0.1:8765 就是那个界面。

容易卡的地方（说明书 §8 有完整对照表）：
- 大屏白屏 → 基本都是 IP 不通或防火墙，先用大屏的浏览器访问 `http://电脑IP:8765` 试一下
- 构建报 JDK 版本错 → 必须是 JDK 17，`ANDROID_HOME` 也要配好
- 按着说话没反应 → 先查麦克风权限；国产大屏可能没有系统语音服务，这种情况先记下来，用文本输入也能验功能

弄完麻烦回传四样：① app-debug.apk ② 大屏实拍或录屏一段（界面 + 一次完整语音问答）③ 说明书 §7 的验收清单打勾版 ④ 卡住的地方和解决办法

## 二、正式版（邮件 / 群公告）

**任务**：企业数字助理（语音助手）安卓大屏部署与联调

**背景**：这是公司内部语音助手，支持制度问答、员工呼叫、企业微信消息、局域网电脑调度。需部署到会议室安卓大屏（Android 7.0+，横屏），用于日常演示与使用。

**交付物**
1. 可安装的 APK 文件（`android/` 工程构建产物）
2. 大屏实拍照片或录屏 1 段，内容含界面展示 + 一次完整语音问答
3. 《任务说明书-安卓大屏APK部署.md》§7 验收清单，逐项打勾后回传
4. 实施过程中遇到的问题与解决办法记录

**执行步骤**（详见包内 `docs/任务说明书-安卓大屏APK部署.md`）
1. 构建机环境：JDK 17 + Android SDK（platform 34 / build-tools 34）+ Gradle
2. `cd android && gradle wrapper --gradle-version 8.7 && ./gradlew assembleDebug`
3. 电脑端启动后端：`python3 -m assistant.hud --host 0.0.0.0 --port 8765`
4. 修改 `android/app/src/main/assets/config.json` 的 `server_url` 为后端机局域网地址后重新构建
5. 通过 adb 或 U 盘安装到大屏，授予麦克风权限，完成联调

**前置条件**：大屏与后端机同网段、8765 端口互通、大屏允许安装未知来源应用。

**时间要求**：本周内完成，如遇阻塞请及时反馈，不必自行硬扛。

## 三、给同事的技术备注（可附在包内，不必发微信）

- 包内节点代理默认 token：`sanwu-demo`（随包 `data/enterprise/devices.json` 内一致，要改两处同改）
- 大屏侧只需 `config.json` 里的 `server_url`；后端 IP 变动时改这一个文件重新构建
- APK 为 debug 包，仅内部演示使用；对外分发需另配 release 签名
- `config.json` 含内网 IP，压缩包与 APK 都不要外传
- 完全离线（不依赖电脑后端）的单机版是下一里程碑，当前版本必须配合电脑端后端使用
